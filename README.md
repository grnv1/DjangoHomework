# CMS 内容管理系统

基于 Python + Django 6 开发的内容管理系统（CMS）原型，具备栏目、文章管理、三级角色权限、多条件查询、收藏、操作日志等功能。

## 功能特性

- **内容管理**：栏目（Category）与文章（Item）的增删改查；发文时选择栏目、关联标签
- **文章发布**：草稿 / 已发布两种状态；支持定时发布（发表时间设为未来时间，到时自动可见）
- **查询功能**：前台支持按标题（模糊）、发表时间（日期区间）、栏目、标签四种条件组合查询
- **三级角色**：
  - 超级管理员：管理用户（创建内容管理员 / 普通用户、启停账号）、管理全部栏目与文章、查看操作日志
  - 内容管理员：管理栏目、仅可操作**自己创建**的文章
  - 普通用户：前台浏览、搜索、收藏
- **软删除**：栏目 / 文章删除为逻辑删除，前台不可见，数据保留
- **操作日志**：记录栏目 / 文章的创建、更新、删除（操作人、类型、对象、时间）
- **收藏**：登录用户可收藏 / 取消收藏文章，提供"我的收藏"页面
- 分页条数、时区、语言均可配置

## 技术栈

- Python 3.12 / Django 6.0
- SQLite（文件型数据库 `db.sqlite3`）
- 服务端页面渲染（HTML 模板 + 表单 + PRG 重定向），无前端框架

## 快速开始

```bash
# 1. 安装依赖
pip install django

# 2. 初始化数据库（建表）
python manage.py migrate

# 3. 生成示例数据（含账号与演示文章）
python manage.py seed

# 4. 启动服务
python manage.py runserver
```

访问 `http://127.0.0.1:8000` 前台，`http://127.0.0.1:8000/admin/` 管理后台。

## 查询功能

前台主页查询区含四个独立条件，可单独或组合使用（AND 关系）：

| 条件 | 参数 | 说明 |
|---|---|---|
| 按标题 | `title` | 标题模糊匹配 |
| 按发表时间 | `date_from` / `date_to` | 发表时间区间（含当天） |
| 按栏目 | `category` | 栏目精确匹配 |
| 按标签 | `tag` | 标签精确匹配 |

栏目页同样支持在栏目内按标题 / 时间 / 标签查询。

## 可见性规则

一篇文章仅当 **未删除 + 已发布（status=1）+ 发表时间 ≤ 当前时间** 时，才在前台可见。

## 权限说明

- 管理后台地址 `/admin/`，需登录且为管理员（`is_staff=True`）；普通用户访问会被重定向回前台
- 用户管理、操作日志页面仅超级管理员可访问（其他管理员访问返回 403）
- 内容管理员只能看到、编辑、删除自己创建的文章；新建文章时作者自动取当前登录人
- 超级管理员不能停用 / 降权自己的账号（自保护）
- 栏目仅"空栏目"（无未删除文章）可删除
