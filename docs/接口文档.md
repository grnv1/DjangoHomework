# CMS 系统接口文档

## 一、概述

- **接口风格**：服务端页面渲染（HTML 模板 + 表单提交 + HTTP 重定向）。
- **开发框架**：Python + Django 6.0。
- **统一约定**：
  - 所有写操作（增、删、改、收藏、登录、注册、登出）一律使用 `POST` 方法，并携带 Django CSRF token（模板表单自动生成）。
  - 采用 **PRG 模式**（Post-Redirect-Get）：表单提交成功后重定向到目标页面，避免刷新/后退导致重复提交。
  - 未登录用户访问需要登录的接口（收藏、我的收藏），跳转到 `/login/?next=<原页面地址>`，登录成功后回跳原页面。
  - 前台页面仅展示"未删除、已发布（status=1）且 publish_time ≤ 当前时间"的文章。
  - 前台界面与自建管理后台界面分离：前台 `/`、`/item/...` 等，管理后台 `/admin/`。

## 二、A. 前台公开接口（匿名可访问）

### A1 主页（文章列表 + 查询 + 分页）

- **URL**：`/`
- **方法**：GET
- **权限**：匿名可访问
- **功能**：展示已发布且已到发表时间的文章列表，支持四种查询条件（可任意组合，AND 关系），支持分页。
- **请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | string | 否 | 文章标题关键词，模糊匹配 |
| date_from | date | 否 | 发表时间区间起始日期（含当天） |
| date_to | date | 否 | 发表时间区间结束日期（含当天） |
| category | int | 否 | 栏目 ID，精确匹配 |
| tag | int | 否 | 标签 ID，精确匹配 |
| page | int | 否 | 页码，默认 1 |

- **成功行为**：返回 HTML 列表页，状态码 200。列表按 `publish_time` 倒序排列，每页固定条数分页。
- **参数异常**：`date_from > date_to` 时给出提示，忽略异常参数正常返回。
- **查询结果为空**：页面提示"未找到相关文章"。

### A2 文章详情

- **URL**：`/item/<int:id>/`
- **方法**：GET
- **权限**：匿名可访问（已删除、草稿或未到发表时间的文章不可访问）
- **功能**：展示文章正文、栏目、作者、发表时间、标签；浏览量 +1；页面内嵌收藏按钮。
- **成功行为**：返回 HTML 详情页，状态码 200。浏览量使用原子自增更新。
- **异常行为**：
  - 文章不存在（含已软删除）→ 404
  - 文章为草稿或未到发表时间 → 404（普通用户不可见，防 URL 猜测）

### A3 栏目文章列表

- **URL**：`/category/<int:id>/`
- **方法**：GET
- **权限**：匿名可访问
- **功能**：展示指定栏目下未删除、已发布且已到发表时间的文章列表，分页。**支持在栏目内查询**（栏目由 URL 固定，可叠加标题 / 发表时间 / 标签条件）。
- **请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | string | 否 | 文章标题关键词，模糊匹配（限定当前栏目内） |
| date_from | date | 否 | 发表时间区间起始日期（含当天） |
| date_to | date | 否 | 发表时间区间结束日期（含当天） |
| tag | int | 否 | 标签 ID，精确匹配 |
| page | int | 否 | 页码，默认 1 |

- **异常行为**：栏目不存在 → 404；栏目下无文章 → 空列表提示。

### A4 注册

- **URL**：`/register/`
- **方法**：GET / POST
- **权限**：匿名可访问
- **功能**：普通前台用户自助注册。
- **请求参数（POST）**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名，唯一 |
| email | string | 否 | 邮箱 |
| password1 | string | 是 | 密码 |
| password2 | string | 是 | 确认密码 |

- **成功行为**：创建普通用户（is_staff=False, is_superuser=False）→ 重定向 `/login/`，状态码 302。
- **失败行为**：用户名已存在 / 两次密码不一致 / 密码强度不足 → 返回 200 并回显错误信息。

### A5 登录

- **URL**：`/login/`
- **方法**：GET / POST
- **权限**：匿名可访问
- **功能**：用户登录（管理员与前台用户共用此入口）。
- **请求参数（POST）**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |
| next | string | 否 | 登录成功后的回跳地址 |

- **成功行为**：建立会话 → 重定向 `next`（若有）或 `/`，状态码 302。
- **失败行为**：用户名或密码错误 → 返回 200 并回显"用户名或密码错误"。

## 三、B. 登录用户接口

### B1 登出

- **URL**：`/logout/`
- **方法**：POST
- **权限**：已登录
- **成功行为**：清除会话 → 重定向 `/`，状态码 302。

### B2 我的收藏

- **URL**：`/favorites/`
- **方法**：GET
- **权限**：已登录
- **功能**：展示当前用户收藏的文章列表（仅未删除、已发布且已到发表时间），分页。
- **请求参数**：`page`（int，可选，默认 1）
- **异常行为**：未登录 → 重定向 `/login/?next=/favorites/`。

### B3 收藏 / 取消收藏（Toggle）

- **URL**：`/favorite/toggle/<int:item_id>/`
- **方法**：POST
- **权限**：已登录
- **功能**：对指定文章执行收藏 / 取消收藏切换：若未收藏则收藏，若已收藏则取消。入口位于**文章详情页**与**我的收藏页**。
- **成功行为**：切换后重定向回来源页面（详情页 `/item/<int:item_id>/`，收藏页 `/favorites/`），状态码 302（PRG 模式）。
- **异常行为**：
  - 未登录 → 重定向 `/login/?next=<来源页面>`
  - 文章不存在（含已软删除）→ 404
  - 收藏页中已软删除 / 草稿 / 未到发表时间的文章不展示，故不会触发取消操作

## 四、C. 管理后台（自建管理页面）

管理后台为**自建页面**（非 Django Admin），所有管理接口要求登录且 `is_staff=True`；普通用户直接访问管理 URL 重定向回前台首页。

### C1 后台首页
- **URL**：`/admin/`，方法 GET，权限：管理员
- **功能**：统计概览 + 各管理功能入口。

### C2 栏目管理
- **URL**：`/admin/category/`（列表）、`/admin/category/create/`、`/admin/category/<int:id>/edit/`、`/admin/category/<int:id>/delete/`
- **方法**：GET（列表 / 表单 / 删除确认）、POST（提交 / 删除执行）
- **权限**：管理员（超级管理员、内容管理员）
- **功能**：栏目的增删改查。删除采用软删除，且仅"空栏目"（无未删除文章）可删；非空栏目的删除入口在列表中显示为禁用态。删除操作先访问确认页（GET），确认后以 POST 执行。
- **异常行为**：栏目下有未删除文章时删除返回提示并拒绝。

### C3 文章管理
- **URL**：`/admin/item/`（列表）、`/admin/item/create/`、`/admin/item/<int:id>/edit/`、`/admin/item/<int:id>/delete/`
- **方法**：GET（列表 / 表单 / 删除确认）、POST（提交 / 删除执行）
- **权限**：管理员（超级管理员、内容管理员）
- **功能**：文章的增删改查；列表支持按标题 / 栏目 / 状态筛选。删除采用软删除，删除操作先访问确认页（GET），确认后以 POST 执行。
- **权限规则**：
  - 内容管理员：列表仅显示自己创建的文章；新建时作者自动取当前登录人（作者字段只读）。
  - 超级管理员：可见全部文章，可指定作者。
- **异常行为**：内容管理员访问他人文章编辑 / 删除 URL → 403。

### C4 用户管理
- **URL**：`/admin/user/`（列表）、`/admin/user/create/`、`/admin/user/<int:id>/edit/`
- **方法**：GET / POST
- **权限**：仅超级管理员
- **功能**：创建内容管理员账号与普通用户、修改资料（用户名 / 邮箱）、调整角色、启停账号、重置密码。**不提供用户物理删除**，账号停用通过 `is_active` 开关实现。
- **自保护**：操作对象为当前登录的超管本人时，页面禁用 / 隐藏"编辑、停用、改角色"入口，服务端亦校验拒绝。
- **角色与组**：角色通过 Django 用户组（`内容管理员` 组）与 `is_superuser` / `is_staff` 组合判定；创建内容管理员时自动加入"内容管理员"组并勾选对应模型权限。

### C5 操作日志
- **URL**：`/admin/log/`
- **方法**：GET
- **权限**：仅超级管理员
- **功能**：查看栏目 / 文章的创建、更新、删除操作记录（操作人、类型、对象、时间）。

### 后台权限规则（对应三级角色）

- **超级管理员**（is_superuser）：可管理全部栏目与文章、创建/管理管理员与普通用户、查看操作日志。
- **内容管理员**（is_staff=True 且非超管）：
  - 栏目：可增删改查，但仅"空栏目"可删除。
  - 文章：仅可查看、修改、删除**自己创建**（author 为本人）的文章；新建文章时作者自动取当前登录人，作者字段只读。
- **普通用户**（is_active，非 staff）：不可访问后台，仅前台浏览。

### 文章管理（后台发布流程）

1. 新建文章，填写标题、正文、选择栏目、关联标签，可设置发表时间。
2. 默认保存为草稿（status=0），`publish_time` 为空。
3. 点击发布（status=1）且 `publish_time` 为空时，自动取当前时间为发表时间。
4. 前台可见规则：`未删除 + status=1 + publish_time ≤ 当前时间`。

## 五、查询参数说明汇总

| 参数 | 适用接口 | 类型 | 过滤逻辑 |
|---|---|---|---|
| title | A1 / A3 | string | `title__icontains`（标题模糊匹配） |
| date_from / date_to | A1 / A3 | date | `publish_time__range`（发表时间区间，含边界） |
| category | A1 | int | `category__exact`（栏目精确匹配） |
| tag | A1 / A3 | int | `tags__exact`（标签精确匹配） |
| page | A1/A3/B2 | int | 分页页码 |

- 多个条件同时填写时为 **AND（并且）** 组合过滤。
- 查询与列表均仅针对"未删除、已发布且已到发表时间"的文章。

## 六、状态码与异常约定

| 状态码 | 场景 |
|---|---|
| 200 | 页面正常返回（含表单校验失败回显） |
| 302 | 提交成功后的重定向（PRG）、未登录跳转登录页 |
| 403 | CSRF 校验失败 / 权限不足（含内容管理员访问他人文章） |
| 404 | 资源不存在，或已删除 / 草稿 / 未到发表时间的文章 |
| 405 | 方法不允许（如对写操作使用 GET） |

|---|---|---|---|
| `/` | GET | 主页（列表+查询+分页） | 公开 |
| `/item/<int:id>/` | GET | 文章详情 | 公开 |
| `/category/<int:id>/` | GET | 栏目文章列表 | 公开 |
| `/register/` | GET/POST | 注册页 | 公开 |
| `/login/` | GET/POST | 登录页 | 公开 |
| `/logout/` | POST | 登出 | 已登录 |
| `/favorites/` | GET | 我的收藏 | 已登录 |
| `/favorite/toggle/<int:item_id>/` | POST | 收藏/取消收藏 | 已登录 |

### 管理后台路由

| 路由 | 方法 | 页面 | 权限 |
|---|---|---|---|
| `/admin/` | GET | 后台首页 | 管理员 |
| `/admin/category/` | GET/POST | 栏目管理（列表/新建） | 管理员 |
| `/admin/category/<int:id>/edit/` | GET/POST | 编辑栏目 | 管理员 |
| `/admin/category/<int:id>/delete/` | GET/POST | 删除栏目（软删除） | 管理员 |
| `/admin/item/` | GET/POST | 文章管理（列表/新建） | 管理员 |
| `/admin/item/<int:id>/edit/` | GET/POST | 编辑文章 | 管理员 |
| `/admin/item/<int:id>/delete/` | GET/POST | 删除文章（软删除） | 管理员 |
| `/admin/user/` | GET/POST | 用户管理（列表/新建） | 超管 |
| `/admin/user/<int:id>/edit/` | GET/POST | 编辑用户 | 超管 |
| `/admin/log/` | GET | 操作日志 | 超管 |
